## Comandos utilizados
- kill: termina um processo
- pgrep: olha todos os processos e pega o id daquele q foi selecionado
- top: serve para mostrar os processos em execução
   - htop: msm q o top so q com uma interface melhor
- jobs: lista de trabalhos q adormecemos
- pkill: mata todos os processos dessa aplicativo
