## Concepts
- Normalmente quando se cria um novo user um novo grupo é criado.
- E quando se usa adduser o shell padrao é o bash, já quando se usa o useradd o shell padrão é o sh
- o sudo siognifica super user do, que serve para ter acesso a partes do sistema que precisa de admin permission para poder correr certos comandos ou permitir certas mudanças no sistema
- sudoers files é oq define quem tem acesso ao super user, e podemos add user que queremos que sejam root diretamente no ficheiro




## Comandos utilizados
- adduser: cria um novo user(sudo required)
- cat /etc/passwd: mostra todos os users do sistema 
- useradd: cria um novo user(sudo required) mas sem pedir dados para preencher como password e nome
- passwd [username]: serve para add a passwrod à algum user(sudo required)
- usermod [username]: serve para modificar dados de um certo user(sudo required)
dar permissão para usar o bash:
````bash
sudo usermod ricarditti --shell /bin/bash
````
mudar o nome de usuário:
````bash
sudo usermod -l ricardo ricarditti
````

permite acessar diretamente ao cli do super user:
````bash
sudo su -
````

melhor maneira para editar arquivos sudo:
````bash
sudo visudo
````

- userdel: serve para apagar users(sudo required)
- groudadd: serve para criar grupos
- cat /etc/group: mostra todos os grupos do sistema
- groups: mostra os grupos que o user pertence
-   :serve para adicionar um user a algum group
````bash
sudo usermod -aG [groupname] [username]
````
  - o <a> é de append
  - o <G> é de group

para remover algum user do group
````bash
sudo gpasswd -d [username] [groupname]
````

- groupdel: serve para apagar um grupo do sistema
