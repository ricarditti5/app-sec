## Conceitos

- Tudo que é instalado em sistema funcionam atraves de pacotes que vem com os programas em si
- Pacotes são gerenciados e instalados pelos package managers como dpgk e apt
- dpkg(low level package manager)
- ficheiros .deb sao instalados em SO baseados no debian
- normalmente o dpkg vai precisar q se instale outros pacotes antes de instalar oq queremos
- os comandos para instalar pacotes funcionam do tipo:
    - apt update: quero todos os pacotes que tem, e o repositorio do apt envia os pacotes
    - apt install [program]: quero os pacotes deste programa se ele existir, se existir o repo retorna os pacotes, caso contrario retorna erro
- apt(high level package manager): this extend to aptitude
- snap-package manager

## Comandos  utilizados
- sudo dpkg -i [ficheiro .deb transferido]
- sudo apt update
- sudo apt install [nome do programa que se quer instalar]
- sudo apt edit-sources(da o caminho para a pasta os pacotes)
- sudo apt - (meio q é um help e mostra oq da para fazer)
- sudo apt list(lista todos os pacotes do repositorio oficial do sistema)
    - apt list --installed(lista todos os pacotes intalados)
- sudo apt show [nome do programa]-(da uma explicação sobre oq é esse programa)
- sudo apt search [nome do programa]
- sudo apt remove [program]-(serve para apagar so o app nao os dados)
- sudo apt purge [program]-(serve para apagar tudo do programa)
- sudo apt upgrade [program]-(serve para atualziar o programa)
    - sudo apt update && sudo apt upgrade [program]-(boas práticas)
    - sudo apt update && sudo apt full-upgrade [program]-(boas práticas + deixa as versoes att da app e remove as antigas)
