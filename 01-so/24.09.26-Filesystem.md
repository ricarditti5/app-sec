## Explicações de coisas basicas
- Tudo no linux está organizado e é gerido por ficheiros.
- Alguns dos comandos como ls, e cat(concatenate) tbm são ficheiros
- Existe uma pasta sbin(super bin)
- o: usr/bin , usr/sbin de um novo user são o msm que está na root do projeto, no caso o second user é uma copia do root user
    - o usr/bin(ficheiro de binarios onde tbm tem os comandos como cat, ls) e usr/sbin(tem os comandos do sudo)
### Tipos de ficheiros no linux:
- boot files: ficheiros do sistema que que tratam da inicialização e etc
- var files: usefull para webApps e também para logs files
- tmp files: ficheiros tmeporários
- lib files: tem todos as lib utilizadas pelo sistema
- etc files: é onde fica a configurações do sistema como networking, server, etc
