# Conceitos

- Terminal: interface na linha de comando(serve para interagir como computador)
- Emulador de terminal: interface onde podemos executar comandos(serve para interagir como computador)
- Shell: UI do terminal

### Tipos de shell:
- bash
- powershell
- kitty
- warp
- ghost

## Comandos para executar
- ps: lista os processos que estão a correr no momento
- netstat: status da internet
- ss: configs de sessao

Caso seje necessario ajuda para comandos usar
````bash
-h | --help | -help | --h
````
